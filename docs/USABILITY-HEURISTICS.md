# QAssure — Usability Heuristic Review

Use this worksheet for the Phase 7 usability validation. Review the authenticated workspace, forms, status transitions, execution flow, defect loop, traceability matrix and quality report.

| # | Nielsen heuristic | Evidence to review |
|---:|---|---|
| 1 | Visibility of system status | Loading, success/error notices, lifecycle states, gate decision |
| 2 | Match between system and real world | QA terminology, test results, defect states and risk scoring |
| 3 | User control and freedom | Cancel actions, project switching, safe lifecycle transitions |
| 4 | Consistency and standards | Common badges, forms, navigation and naming |
| 5 | Error prevention | Required fields, enum choices, server-side state guards |
| 6 | Recognition rather than recall | Project context, linked codes, expected result visible during execution |
| 7 | Flexibility and efficiency | Direct module navigation and compact QA workflows |
| 8 | Aesthetic and minimalist design | Relevant QA evidence without decorative clutter |
| 9 | Help users recognize/recover from errors | API error messages and invalid transition feedback |
| 10 | Help and documentation | Phase docs, README, test evidence and release checklist |

For each finding record: screen/module, heuristic, observation, severity (0–4), recommended correction, status, and evidence reference.
