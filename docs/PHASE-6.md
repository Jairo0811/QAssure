# Phase 6 — Quality Reports, Metrics & Quality Gates

QAssure consolidates project quality into a release-oriented report.

## Metrics

Requirements, approved requirements, requirement coverage, test cases, ready cases, test runs, completed runs, execution outcomes, pass rate, defects, open defects, critical defects, and final-validation coverage.

## Release quality gate

| Check | Threshold |
|---|---|
| Requirement coverage | ≥ 95% |
| Pass rate | ≥ 90% |
| Completed test run | ≥ 1 |
| Pending executions | 0 |
| Critical open defects | 0 |
| Critical open risks | 0 |
| Final validation areas | 4/4 Passed |

The decision is `Ready`, `Conditional`, or `Blocked`. Critical open defects, pending executions, or absence of a completed cycle are blocking conditions.
