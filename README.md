# QAssure

**Software Quality Assurance Platform**

> Verify. Validate. Assure.

QAssure is a software quality assurance platform created for **ISO-410 — Verificación y Validación de Software** at Universidad APEC. The project centralizes requirements, risks, test cases, test executions, defects, traceability, quality metrics, and validation evidence in a single workflow.

## Vision

QAssure is designed to make software quality measurable and traceable. The platform will support the complete QA lifecycle:

`Requirements → Risks → Test Cases → Test Runs → Defects → Re-test → Regression → Validation → Quality Report`

## Planned stack

- **Backend:** ASP.NET Core 10 Web API
- **Data:** Entity Framework Core + SQL Server
- **Frontend:** React + TypeScript + Vite
- **Unit/Integration Testing:** xUnit
- **E2E:** Playwright
- **API Testing:** Postman/Newman
- **Performance:** k6
- **CI:** GitHub Actions

## Core modules

1. Authentication & Roles

7. Defects
8. Traceability Matrix

## QA principles

QAssure is intentionally built as a system that can also be tested with the same verification and validation techniques it manages, including equivalence partitioning, boundary value analysis, decision tables, state transitions, use-case testing, regression, performance, security, usability, and user acceptance testing.
